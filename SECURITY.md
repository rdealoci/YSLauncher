# Security Policy

## Reporting Security Vulnerabilities

Security, transparency, and integrity are top priorities for this project.

If you believe you have discovered a security vulnerability, flaw, or potential exploit in YSLauncher, please report it privately:

1. Navigate to the **Security** tab of this repository on GitHub.
2. Click on **Report a vulnerability** (Private Vulnerability Reporting).
3. Provide a detailed summary, including:
   - Steps to reproduce or proof-of-concept.
   - Affected platforms (Windows, Linux, macOS).
   - Potential impact.

Please do **NOT** disclose vulnerabilities or sensitive exploit details in public GitHub Issues or public forums before an evaluation and fix can be prepared.
