# Contributing to YSLauncher

Thank you for your interest in YSLauncher.

## Maintenance Model
This repository operates under a **source-available, author-maintained model**:
- **Code contributions are not accepted**: Pull Requests (PRs) are disabled and external code modifications will not be merged.
- **Development is individual**: All development decisions, roadmap planning, updates, and releases are managed exclusively by the author.

## How to Help
While code contributions are closed, community feedback and issue reports are very welcome!

### Bug Reports
If you run into a crash, installation problem, update issue, or unexpected behavior:
1. Check the [Issues](https://github.com) tab to see if the problem has already been reported.
2. If not, open a new **Bug Report** with details about your operating system, launcher version, and steps to reproduce.

### Security Vulnerabilities
If you discover a potential security vulnerability, please do **not** open a public issue. Follow the instructions in [SECURITY.md](SECURITY.md) to report it privately.
